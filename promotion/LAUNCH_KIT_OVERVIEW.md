## Strict Anti-Spam & Ethics Policy

1. **Zero Financial Claims:** `MNC` is consistently described as an experimental Ethereum Sepolia (`11155111`) testnet token with zero monetary value.
2. **Zero Fake Metrics:** Every test count (`20/20`, `12/12`, `30,000` fuzz runs, `6/6` recovery checks, `60/60` Python consensus checks) matches live repository execution.
3. **Zero Mass Messaging:** Posts are designed for organic, single-submission developer feedback after project lead approval.
